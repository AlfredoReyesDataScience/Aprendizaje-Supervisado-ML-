## Qué se analizó

Una serie de aplicaciones de distintos modelos de Aprendizaje supervisado de Machine Learning. Desde generación de imágenes como predicciones para saber si una persona podría tener un ataque al corazón así como comparación entre distintos modelos.

## Técnicas utilizadas

Análisis exploratorio

Modelo KNN

Regresión Logística


 ## Resultados principales

Se obtuvieron predicciones para saber si un paciente era propenso a tener un ataque al corazón mediante KNN.

Se reconoció una imagen para replicarla mediante KNN y se comparó la misma técnica con Regresión Logística en sus distintas variantes, escogiendo la mejor
